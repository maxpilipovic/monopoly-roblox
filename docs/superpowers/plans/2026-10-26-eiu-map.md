# EIU Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third map, EIU: Eastern Illinois / Charleston names, EIU Chance, Chest and Crazy decks (with two new crazy effects), EIU emblems and card art from Blender, and an EIU Campus scene that always surrounds an EIU game.

**Architecture:** Map data stays in `Tiles`/`Cards` (one active map, switched by `Maps.use`). Per-map presentation (card nouns, card art, emblem shapes, board colours) moves to a small shared lookup keyed by map id instead of the `college.` prefix checks. The scene stays a client-built SceneKit module; a scene can name the one map it belongs to, and `RoomSettings.validate` enforces the pairing.

**Tech Stack:** Luau (strict), Rojo, the in-repo test runner (Studio RunTests hook), Blender via blender-mcp with `tools/blender/*.py`, `tools/upload-assets.ps1`.

**Spec:** `docs/superpowers/specs/2026-10-26-eiu-map-design.md` (the tile table and all card text there are copied verbatim into code).

## Global Constraints

- Map id `"EIU"`, label `"EIU"`. College and Classic unchanged; ranked queue rooms stay Classic.
- No alcohol anywhere: bars are "hangouts" by name only; no drinks, bottles, mugs, kegs, drinking, drunk, blackout, hangover, fake ID — in text, models, renders or scenery. No hazing. No official EIU logo, seal, wordmark art or Billy the Panther design.
- Card ids: `eiu.<classic id>` (Chance, Chest), `eiu.crazy.<name>` (EIU crazy deck). Deck titles: Saturday Night / Care Package / Crazy Night.
- Nouns on EIU: Railroad → "hangout", Utility → "delivery".
- Every EIU name and card line lives in a data table (owner will edit them).
- Art is Blender, never emoji. Fronts face Blender +Y; 1 unit = 1 stud (`tools/blender/common.py`).
- Run tests with the RunTests hook (project memory `studio-mcp-sandbox`); before each run confirm Studio has the newest source (memory `rojo-branch-switch-crash`). Never `git switch` to main; fast-forward with `git branch -f main feat/eiu-map`.

## Review Focus

1. **A board left over from an EIU game shown for a Classic game** (or the reverse) — names, colours and emblems must all follow the new map. Test in Task 5: `BoardBuilder.restyle` after switching maps sets Classic colours back.
2. **Host switches map away from EIU while the scene is EIU Campus** — must fall back to the default scene, not keep a map-locked one. Test in Task 7.
3. **Matched (queue) rooms pick a random scene** — must never pick EIU Campus for a Classic game. Test in Task 7.
4. **BailOut when the drawer can't afford all the bail** — each release still happens, the unpaid part becomes ordinary debt, the game doesn't stall. Test in Task 3.
5. **RaidKind with the drawer on a hangout and Jail already holding people** — the drawer goes too; nobody is jailed twice. Test in Task 3.
