# Trading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On their turn (or while settling their own debt), a player offers another player a trade of deeds, cash and jail cards. The receiver accepts or declines. Bots judge offers by value.

**Architecture:**
- **Legality lives in one place.** A pure shared `TradeRules` module decides whether an offer is legal from a plain view (properties + parties). The engine validates with it, and so does the client's trade builder.
- **Engine.** A new `Trade` phase stores the offer in `state.trade`, pauses on the receiver, and returns to the phase it came from (Roll, EndTurn or Debt). Accepting swaps assets and charges the 10% mortgage interest through the existing `charge`, so an unaffordable interest becomes a normal debt.
- **Bots** answer by value.
- **Client.** A pure `TradeBuilder` module holds the trade window's selections, and `HudView` renders it.

**Tech Stack:** Luau (`--!strict`), Rojo 7.7, in-Studio test runner, Studio MCP for playtests.

**Spec:** `docs/superpowers/specs/2026-09-28-trading-design.md` (read it; this plan implements it). Builds on `docs/superpowers/plans/2026-09-28-debt-and-bankruptcy.md`.

## Global Constraints

- **Who proposes:** the current player in `Roll` or `EndTurn`, or the debtor at the head of the queue in `Debt`. Never in BuyDecision, Auction, Trade or GameOver.
- **Answering:** accept or decline only, by the receiver only. No counter-offers.
- **Offer limit:** at most 3 offers per player per turn (`Engine.MAX_TRADE_OFFERS = 3`), counted on proposal and reset when the turn ends.
- **What can be traded:**
  - deeds each side owns, but no street whose color set has any buildings ("sell the buildings in this set first");
  - whole-dollar cash from 0 up to what that side has;
  - whole-number jail cards from 0 up to what that side holds;
  - at least one thing must change hands.
- **Mortgaged deeds** change hands still mortgaged. The receiver of each is charged `unmortgageCost − mortgageValue` by the bank through `charge`.
- **Offers are validated** on proposal and again on accept. A refused accept leaves the offer open.
- **Bot valuation:**
  - cash counts at face value;
  - a jail card is worth $50;
  - a deed is worth its price, or `price − unmortgageCost` if mortgaged;
  - a street counts double when it completes the bot's set (received), or completes the proposer's set (given away);
  - the bot accepts when `received ≥ 1.1 × given` and it keeps ≥ `Bot.CASH_RESERVE` after paying cash; it always accepts gifts.
- **Log lines:**
  - "{from} offered {to} {give} for {get}", where items are joined with " + " and an empty side reads "nothing";
  - "{to} accepted the trade" / "{to} declined the trade".
- **Out of scope:** bots proposing, counter-offers, trading buildings, timers.
- Every new `.luau` file starts with `--!strict`. Tabs.

## Review Focus

1. **A debtor proposes a trade.** The engine's after-action hook must not flip the new `Trade` phase back into `Debt`: the receiver must get to answer, then play returns to the debt. Pinned by Trade.spec "a debtor can trade for cash and then pay".
2. **A receiver who gets a mortgaged deed and can't afford the interest.** They go into debt to the bank, and afterwards play resumes in the proposer's phase. Pinned by Trade.spec "interest the receiver can't pay becomes a debt, then the turn resumes".
3. **A tampered client sends garbage offers:**
   - NaN, negative, fractional or infinite cash or jail-card counts;
   - duplicate positions, or the same deed on both sides;
   - a non-purchasable tile, or a dictionary instead of a list;
   - an offer to yourself or to a bankrupt player.

   Each must be rejected with no state change. Pinned by TradeRules.spec "malformed offers are refused" and Trade.spec "garbage offers change nothing".
4. **The fourth offer in a turn.** It is refused with a clear reason, and the HUD's Trade button disappears when none are left. Pinned by Trade.spec "three offers per turn, reset when the turn ends" and HudModel.spec "the Trade button shows only when you may propose".
5. **A bot asked for cash it can't spare.** It declines even if the deal is good. Pinned by Bot.spec "a bot keeps its cash reserve in trades".

```lua
--!strict
-- Whether a trade offer is legal. Pure: works on any view of the properties plus a table of the
-- parties, so the server (GameState) and the trade window (snapshot) agree on what may be sent.

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Tiles = require(ReplicatedStorage.Shared.Board.Tiles)
local PropertyRules = require(ReplicatedStorage.Shared.Rules.PropertyRules)

export type Side = {
	properties: { number }, -- board positions
	cash: number,
	jailCards: number,
}

export type Offer = {
	to: string,
	give: Side, -- from the proposer
	get: Side, -- from the receiver
}

export type Party = {
	id: string,
	name: string,
	money: number,
	jailCards: number,
	bankrupt: boolean,
}

local TradeRules = {}

local PURCHASABLE = { Property = true, Railroad = true, Utility = true }

-- Whole, finite and not negative. NaN fails `x == x`; infinity fails `x % 1 == 0` (inf % 1 is NaN).
local function isCount(value: any): boolean
	return typeof(value) == "number" and value == value and value % 1 == 0 and value >= 0
end

local function isDeedList(value: any): boolean
	if typeof(value) ~= "table" or #value > Tiles.COUNT then
		return false
	end
	local count = 0
	for key, position in value do
		count += 1
		if typeof(key) ~= "number" or not isCount(position) or position >= Tiles.COUNT then
			return false
		end
		if not PURCHASABLE[Tiles.at(position).kind] then
			return false
		end
	end
	return count == #value -- a proper list, no holes or extra keys
end

local function isSide(value: any): boolean
	return typeof(value) == "table" and isDeedList(value.properties) and isCount(value.cash) and isCount(value.jailCards)
end

function TradeRules.tradable(view: PropertyRules.View, position: number): (boolean, string?)
	local tile = Tiles.at(position)
	if tile.kind == "Property" then
		for _, other in PropertyRules.groupPositions(tile.group :: string) do
			local ownership = view.properties[other]
			if ownership and ownership.houses > 0 then
				return false, "sell the buildings in this set first"
			end
		end
	end
	return true
end

function TradeRules.validate(
	view: PropertyRules.View,
	parties: { [string]: Party },
	fromId: string,
	offer: any
): (boolean, string?)
	if typeof(offer) ~= "table" or not isSide(offer.give) or not isSide(offer.get) then
		return false, "invalid offer"
	end
	local to = if typeof(offer.to) == "string" then parties[offer.to] else nil
	local from = parties[fromId]
	if not to or not from or to.id == fromId then
		return false, "pick another player"
	elseif to.bankrupt then
		return false, "that player is out of the game"
	end

	local give: Side, get: Side = offer.give, offer.get
	local seen = {}
	for _, list in { give.properties, get.properties } do
		for _, position in list do
			if seen[position] then
				return false, "invalid offer"
			end
			seen[position] = true
		end
	end
	if #give.properties + #get.properties + give.cash + get.cash + give.jailCards + get.jailCards == 0 then
		return false, "the offer is empty"
	end

	for _, position in give.properties do
		local ownership = view.properties[position]
		if not ownership or ownership.owner ~= fromId then
			return false, `you don't own {Tiles.at(position).name}`
		end
	end
	for _, position in get.properties do
		local ownership = view.properties[position]
		if not ownership or ownership.owner ~= to.id then
			return false, `{to.name} doesn't own {Tiles.at(position).name}`
		end
	end
	for position in seen do
		local ok, err = TradeRules.tradable(view, position)
		if not ok then
			return false, err
		end
	end

	if give.cash > from.money then
		return false, "you don't have that much cash"
	elseif get.cash > to.money then
		return false, `{to.name} doesn't have that much cash`
	elseif give.jailCards > from.jailCards then
		return false, "you don't have that many jail cards"
	elseif get.jailCards > to.jailCards then
		return false, `{to.name} doesn't have that many jail cards`
	end
	return true
end

local function copySide(side: Side): Side
	return { properties = table.clone(side.properties), cash = side.cash, jailCards = side.jailCards }
end

function TradeRules.copy(offer: Offer): Offer
	return { to = offer.to, give = copySide(offer.give), get = copySide(offer.get) }
end

return TradeRules
```

```lua
local function proposeTrade(state: GameState, player: Player, offer: any): (boolean, string?)
	if (state.tradeOffers[player.id] or 0) >= Engine.MAX_TRADE_OFFERS then
		return false, "no trade offers left this turn"
	end
	local ok, err = TradeRules.validate(state, Engine.tradeParties(state), player.id, offer)
	if not ok then
		return false, err
	end
	local copy = TradeRules.copy(offer)
	state.trade = { from = player.id, offer = copy, returnPhase = state.phase }
	state.tradeOffers[player.id] = (state.tradeOffers[player.id] or 0) + 1
	state.phase = "Trade"
	emit(state, {
		type = "TradeProposed",
		from = player.id,
		to = copy.to,
		give = TradeRules.copy(copy).give,
		get = TradeRules.copy(copy).get,
	})
	return true
end

local function moveJailCards(from: Player, to: Player, count: number)
	for _ = 1, count do
		table.insert(to.jailCards, table.remove(from.jailCards, 1) :: string)
	end
end

local function closeTrade(state: GameState, trade: Types.PendingTrade)
	state.trade = nil
	state.phase = trade.returnPhase
end

local function acceptTrade(state: GameState): (boolean, string?)
	local trade = state.trade :: Types.PendingTrade
	local ok, err = TradeRules.validate(state, Engine.tradeParties(state), trade.from, trade.offer)
	if not ok then
		return false, err
	end
	local offer = trade.offer
	local from = Engine.getPlayer(state, trade.from) :: Player
	local to = Engine.getPlayer(state, offer.to) :: Player

	local interest = {} -- { payer, position } for each mortgaged deed that changes hands
	local function hand(positions: { number }, receiver: Player)
		for _, position in positions do
			local ownership = state.properties[position]
			ownership.owner = receiver.id
			if ownership.mortgaged then
				table.insert(interest, { payer = receiver, position = position })
			end
		end
	end
	hand(offer.give.properties, to)
	hand(offer.get.properties, from)
	if offer.give.cash > 0 then
		transfer(state, from.id, to.id, offer.give.cash, "Trade")
	end
	if offer.get.cash > 0 then
		transfer(state, to.id, from.id, offer.get.cash, "Trade")
	end
	moveJailCards(from, to, offer.give.jailCards)
	moveJailCards(to, from, offer.get.jailCards)
	for _, due in interest do
		local amount = PropertyRules.unmortgageCost(due.position) - PropertyRules.mortgageValue(due.position)
		charge(state, due.payer, nil, amount, "MortgageInterest")
	end

	emit(state, { type = "TradeAccepted", from = from.id, to = to.id })
	closeTrade(state, trade)
	return true
end

local function declineTrade(state: GameState)
	local trade = state.trade :: Types.PendingTrade
	emit(state, { type = "TradeDeclined", from = trade.from, to = trade.offer.to })
	closeTrade(state, trade)
end

local function actInTrade(state: GameState, player: Player, action: Types.Action): (boolean, string?)
	local trade = state.trade :: Types.PendingTrade
	if trade.offer.to ~= player.id then
		return false, "waiting for another player to answer a trade"
	elseif action.type == "AcceptTrade" then
		return acceptTrade(state)
	elseif action.type == "DeclineTrade" then
		declineTrade(state)
		return true
	end
	return false, "answer the trade first"
end
```

```lua
-- Whether owner holds a street's whole color set once gained/lost deeds change hands.
local function completesSet(state: Types.GameState, ownerId: string, position: number, gained: { number }, lost: { number }): boolean
	local tile = Tiles.at(position)
	if tile.kind ~= "Property" then
		return false
	end
	for _, other in PropertyRules.groupPositions(tile.group :: string) do
		local ownership = state.properties[other]
		local keeps = ownership ~= nil and ownership.owner == ownerId and not table.find(lost, other)
		if not keeps and not table.find(gained, other) then
			return false
		end
	end
	return true
end

local function deedValue(state: Types.GameState, position: number): number
	local price = Tiles.at(position).price :: number
	return if state.properties[position].mortgaged then price - PropertyRules.unmortgageCost(position) else price
end

-- A deal is worth taking when what the bot gets is at least TRADE_MARGIN_TENTHS/10 of what it gives.
local function acceptsTrade(state: Types.GameState, me: Types.Player, trade: Types.PendingTrade): boolean
	local offer = trade.offer
	local received = offer.give.cash + offer.give.jailCards * Bot.JAIL_CARD_VALUE
	for _, position in offer.give.properties do
		local worth = deedValue(state, position)
		received += if completesSet(state, me.id, position, offer.give.properties, offer.get.properties) then 2 * worth else worth
	end
	local given = offer.get.cash + offer.get.jailCards * Bot.JAIL_CARD_VALUE
	for _, position in offer.get.properties do
		local worth = deedValue(state, position)
		given += if completesSet(state, trade.from, position, offer.get.properties, offer.give.properties) then 2 * worth else worth
	end
	if given == 0 then
		return true
	elseif offer.get.cash > 0 and me.money - offer.get.cash < Bot.CASH_RESERVE then
		return false
	end
	return received * 10 >= given * Bot.TRADE_MARGIN_TENTHS
end
```

```lua
--!strict
-- The trade window's working offer: who it's for and what each side puts in. Pure, so the
-- window only draws it; TradeRules (the same rules the server uses) decides if it may be sent.

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Protocol = require(ReplicatedStorage.Shared.Net.Protocol)
local Tiles = require(ReplicatedStorage.Shared.Board.Tiles)
local TradeRules = require(ReplicatedStorage.Shared.Rules.TradeRules)
local HudModel = require(script.Parent.HudModel)

export type SideName = "give" | "get"

export type Builder = {
	partner: string?,
	give: TradeRules.Side,
	get: TradeRules.Side,
}

export type DeedRow = {
	position: number,
	name: string,
	selected: boolean,
	tradable: boolean,
	reason: string?,
}

local TradeBuilder = {}

local function emptySide(): TradeRules.Side
	return { properties = {}, cash = 0, jailCards = 0 }
end

function TradeBuilder.new(): Builder
	return { partner = nil, give = emptySide(), get = emptySide() }
end

function TradeBuilder.setPartner(builder: Builder, id: string)
	builder.partner = id
	builder.give = emptySide()
	builder.get = emptySide()
end

function TradeBuilder.toggle(builder: Builder, sideName: SideName, position: number)
	local properties = builder[sideName].properties
	local index = table.find(properties, position)
	if index then
		table.remove(properties, index)
	else
		table.insert(properties, position)
	end
end

function TradeBuilder.stepCash(builder: Builder, sideName: SideName, delta: number, max: number)
	local side = builder[sideName]
	side.cash = math.clamp(side.cash + delta, 0, math.max(max, 0))
end

function TradeBuilder.stepJailCards(builder: Builder, sideName: SideName, delta: number, max: number)
	local side = builder[sideName]
	side.jailCards = math.clamp(side.jailCards + delta, 0, math.max(max, 0))
end

function TradeBuilder.offer(builder: Builder): TradeRules.Offer
	return TradeRules.copy({ to = builder.partner or "", give = builder.give, get = builder.get })
end

function TradeBuilder.partners(snapshot: Protocol.Snapshot, localId: string): { { id: string, name: string } }
	local partners = {}
	for _, player in snapshot.players do
		if player.id ~= localId and not player.bankrupt then
			table.insert(partners, { id = player.id, name = player.name })
		end
	end
	return partners
end

function TradeBuilder.rows(snapshot: Protocol.Snapshot, ownerId: string, side: TradeRules.Side): { DeedRow }
	local view = HudModel.rulesView(snapshot)
	local rows = {}
	for _, property in snapshot.properties do -- already sorted by position
		if property.owner == ownerId then
			local tradable, reason = TradeRules.tradable(view, property.position)
			table.insert(rows, {
				position = property.position,
				name = Tiles.at(property.position).name,
				selected = table.find(side.properties, property.position) ~= nil,
				tradable = tradable,
				reason = reason,
			})
		end
	end
	return rows
end

function TradeBuilder.check(snapshot: Protocol.Snapshot, localId: string, builder: Builder): (boolean, string?)
	if not builder.partner then
		return false, "pick a player"
	end
	local parties = {}
	for _, player in snapshot.players do
		parties[player.id] = {
			id = player.id,
			name = player.name,
			money = player.money,
			jailCards = player.jailCards,
			bankrupt = player.bankrupt,
		}
	end
	return TradeRules.validate(HudModel.rulesView(snapshot), parties, localId, TradeBuilder.offer(builder))
end

return TradeBuilder
```
